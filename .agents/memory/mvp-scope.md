---
name: MVP scope
description: The user-defined scope boundary for the initial card-game prototype.
---

The MVP is the core four-player, two-team suit-deduction game. Akuma mode and its special abilities are not part of the prototype.

**Why:** the user explicitly excluded Akuma mode from the MVP.

**How to apply:** Keep the baseline 2v2 loop focused on private team hands, public reveals, suit guesses, and turn order; add Akuma abilities only if the user changes the scope.
