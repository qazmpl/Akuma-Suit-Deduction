# 🃏 ACMA MATRIX // 2v2 Tactical Card Deduction Engine

A mobile-first, room-based **2v2 competitive card deduction game** built on a clean, lightweight standalone frontend stack (`index.html`, `style.css`, `script.js`).

Designed specifically for **native Android APK compilation** and ultra-smooth mobile web execution over cellular networks with zero heavy frameworks, database dependencies, or build tooling required.

## 📐 Core Game Loop & Mathematical Matrix

### 1. The Deck Structure
- **15 Cards Total:** 5 unique suits (♠ Spades, ♥ Hearts, ♦ Diamonds, ♣ Clubs, 👿 Demon).
- **Exact Distribution:** Exactly 3 identical cards per suit. Cards have no numbers; they represent pure suit vectors.
- **The Target:** 1 card is drawn at round initialization and locked into the classified **Target Vault**. Deduce this suit to win.
- **Shared Team Hands:** 3 cards are dealt to Team Alpha (A) and 3 cards to Team Omega (B). These cards belong to the team universally as a shared container array.
- **Remaining Draw Pile:** Exactly 8 cards remain in the deck for replenishment.

### 2. Strict 4-Player Turn Rotation
```
Team A Player 1 (A1) ➔ Team B Player 1 (B1) ➔ Team A Player 2 (A2) ➔ Team B Player 2 (B2) ➔ (Repeat)
```

### 3. Action Flow on Active Turn
On their turn, the active player can execute **one** of two choices:
1. **Reveal & Draw:**
   - Select 1 to 3 cards from their team hand.
   - Reveal them into the public **Cemetery Log**.
   - Automatically draw replacement cards from the remaining draw pile.
   - Rewards `+10 points` to the active player's invisible round score.
   - Passes turn to the next operative in the rotation loop.
2. **Submit Final Deduction (Guess):**
   - Choose one of the non-eliminated suits.
   - **Correct Guess:** Round won instantly by active player's team! `+50 points` awarded to *both* teammates. Target card revealed with victory fanfare.
   - **Incorrect Guess:** Flashes error state, that suit is permanently deactivated globally for future guesses, `-30 points` deducted from active player, and turn passes.

## 🥷 The Hidden Rating & Equalization Engine

### Invisible Points System
Players never see numerical points or scores on the UI; all scoring is strictly maintained in the room state:
- **Reveal Action:** `+10 points`
- **Correct Guess:** `+50 points` (to both teammates on the winning team)
- **Incorrect Guess:** `-30 points` (strictly from the active guesser)
- **Round End Formula:**
  $$\text{newRating} = (\text{pointsThisRound} \times 0.7) + (\text{previousRating} \times 0.3)$$

### Host Rebalance Matrix
At round conclusion, the host has access to the **"⚡ EQUALIZE & REBALANCE MATRIX"** action:
1. Sorts all 4 connected operatives by computed `rating` descending ($Rank_1$ to $Rank_4$).
2. Automatically pairs **Rank 1 + Rank 4** into **Team Alpha (A)**.
3. Automatically pairs **Rank 2 + Rank 3** into **Team Omega (B)**.
4. Flushes all hands, resets deck pointers, clears cemetery, and instantly transitions into the next round seamlessly within the exact same session container!

## 📱 Multi-Device Architecture & Mobile Security

1. **Strict Multi-Device Synchronization:**
   - Real-time WebSocket pipeline using the public proxy:
     `wss://api.piesocket.com/v3/demo?api_key=VCXCEuvYube6tgDo148wZ2Pp39369A8sESmYswPM`
   - Messages are isolated via an envelope structure:
     `{ roomId, senderId, type, payload, timestamp }`
   - Rooms are identified by a unique 4-character code (e.g. `K9X2`).
2. **Local UI Isolation (Anti-Peeking):**
   - Card selection states exist purely in client-side local memory (`localSelectedIndices`). Opponents and teammates never see card touches until an action is executed.
   - **Privacy Visor:** A dedicated "HIDE HAND / PEEK" toggle on the hand dock applies a local frosted shield so players sitting next to friends can hide their screen.
3. **Touch-First Optimization:**
   - Zero sticky `:hover` states on touch displays.
   - Full support for `env(safe-area-inset-top)` and `env(safe-area-inset-bottom)`.
4. **Hot-Swap Re-entry:**
   - Every session is serialized to `localStorage`. If a player reloads or drops connection, the client hot-swaps them straight back into their designated seat without login barriers.
5. **Instant Solo Practice / Auditor Mode:**
   - Includes a one-click **"Instant Solo Practice & Test Loop"** button that auto-populates 3 AI bot operatives with deductive decision-making logic so a developer can test the entire 4-player loop single-handedly.

## 🚀 Native Android APK Compilation Guide

To compile this project into a native Android APK:

### Option A: Using Capacitor (Recommended)
1. Initialize Capacitor in the project directory:
   ```bash
   npm init -y
   npm install @capacitor/core @capacitor/cli @capacitor/android
   npx cap init "ACMA Matrix" "com.acma.matrix" --web-dir "."
   ```
2. Add the Android platform:
   ```bash
   npx cap add android
   npx cap copy
   ```
3. Open and build in Android Studio:
   ```bash
   npx cap open android
   ```
   Select **Build > Build Bundle(s) / APK(s) > Build APK(s)**.

### Option B: Using Apache Cordova
```bash
cordova create acma-matrix com.acma.matrix "ACMA Matrix"
# Copy index.html, style.css, script.js, manifest.json into the www/ folder
cordova platform add android
cordova build android --release
```

### Option C: Direct Mobile Browser / PWA
Simply serve the directory via any static web server (or GitHub Pages / Cloudflare Pages / Vercel) and tap **"Add to Home Screen"** in Chrome on Android or Safari on iOS for a fullscreen app experience.
